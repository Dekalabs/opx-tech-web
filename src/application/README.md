# APPLICATION LAYER

This directory contains the **application layer** where the use cases defines the behavior of our application, what our application does at a high-level; they are the recipes for our features; the main units of the application layer. They define the application itself.

It is responsible for performing interactions among units of the [domain layer](../domain/README.md). 

The application layer can also be used as an adapter to the infrastructure layer.
