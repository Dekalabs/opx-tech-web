# LOCALES

In the locales directory will be the language files in json. The files needed by i18n or the internationalization to make the translations. 

With [Vite plugin vue i18n](https://github.com/intlify/bundle-tools/tree/main/packages/vite-plugin-vue-i18n), Vite will load the locales with a better performance:

- i18n resources pre-compilation
- i18n custom block
- Static bundle importing
- Bundling optimizations
